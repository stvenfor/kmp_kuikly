# H5 smoke

## Module

`h5App/` is a real JS Shell (Maven `core-render-web`). Business bundle from `:app-shared`.

## Run

```bash
./gradlew :app-shared:packLocalJsBundleDebug
./gradlew :h5App:jsBrowserDevelopmentRun -t
# http://localhost:8080/?page_name=Home
```

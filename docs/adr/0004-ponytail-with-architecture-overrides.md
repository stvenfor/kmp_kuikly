# Ponytail always-on for implementation

We adopt [Ponytail](https://github.com/DietrichGebert/ponytail) (`alwaysApply`) so agents climb the YAGNI ladder and ship the shortest correct diff. Architecture tickets and ADRs remain explicit requirements — Ponytail must not delete planned Feature/Platform modules, four-platform ports, or Kuikly contracts just to write less code.
